# 9 - Requisitos de Infraestrutura

## 9.1 Sistema Gerenciador de Banco de Dados

**SGBD:** MySQL

**Ambiente do banco de dados:** XAMPP

**ORM:** Prisma

**Versão do Prisma:** 7.10.0

**Banco de dados:** `preparacao_db`

O banco de dados MySQL foi executado localmente através do XAMPP e a aplicação utiliza o Prisma como ORM para realizar a comunicação entre o Backend e o banco de dados

## 9.5 Requisitos Mínimos para Execução

- Computador com sistema operacional Windows
- Node.js instalado
- XAMPP instalado
- MySQL ativo no XAMPP
- Banco de dados `preparacao_db` criado
- Prisma configurado no projeto
- Navegador Web atualizado
- Conexão com o banco de dados configurada no projeto
